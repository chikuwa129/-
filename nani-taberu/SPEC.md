## 目的
食べたい料理が思いつかない時に、数問の質問に答えるだけで料理候補を絞り込むアプリ。
「今日どのくらい作る気があるか」（やる気度）を軸に、無理なく作れる料理を選べるのが特徴。
「トマト系が食べたい」のように、食材や料理名から入ることもできる。
事前に登録した自分のプロフィールと、今の時間・状況・近所のスーパーの営業時間を踏まえて、「今からならこう動く」という段取りまで提案する。
さらに、提案した料理と実際に食べた料理を内部カレンダーに記録し、食事のバランスを考えた提案ができるようにする。

## 食材・料理名の指定（A）
- dishes.json の各料理に ingredients（{ name, role: main|sub }）。食材名は ingredients.json の正規名にそろえる。main 1〜3、sub 0〜5、調味料は入れない
- ingredients.json：正規名 → { aliases, category }。照合前に入力を正規化（ひらがな／カタカナ、全角／半角、英字小文字、前後空白）
- カテゴリ語（「きのこ」「豆腐系」など）はそのカテゴリの食材を持つ料理すべてが対象
- 料理名は部分一致（「カレー」→名前にカレーを含む料理）。aliases も照合
- スコア：main +3、sub +1、料理名 +3、当たらない料理は加点なし
- 3品以上当たったら当たった料理だけに絞る。1〜2品なら必ず残して近い料理も加え「『トマト』を使う料理は2品でした。近い料理も入れています」
- 複数指定は AND（両方使う）を上位、足りなければ OR
- 否定（以外／は嫌／抜き／なしで）はその食材を使う料理を除外（sub 含む）
- やる気度と同時に効く。食材で絞った結果がやる気度の範囲外ばかりなら、やる気度を先に緩和して表示
- 辞書にあるが料理データにない食材：「『◯◯』を使う料理はデータにありませんでした」＋同カテゴリの料理で代替、console に警告
- どれにも当たらない：「うまく読み取れませんでした」→アキネーターモードへ
- 読み取った言葉を決定直後に確認表示し、タグをタップで外せる。結果画面に理由を1行

## やる気度（B）
| レベル | 表示名 | 意味 |
|---|---|---|
| 0 | 作りたくない | 買う・外食・お惣菜で済ませたい |
| 1 | 温めるだけ・茹でるだけ | 包丁なし。レンジ・お湯・混ぜる程度。1工程 |
| 2 | 炒める・焼くだけ | 包丁はほぼなし。フライパン1つ |
| 3 | ふつうに作れる | 包丁OK。数工程あってもよい |
| 4 | 凝りたい | 煮込み・仕込みなど |

- 料理に effort（1〜4）、knife（不要/少し/必要）、method（温める/茹でる/炒める/焼く/煮る/揚げる/和える/混ぜる）、deliAlt
- effort 1 は knife 不要のみ、effort 2 は不要か少し
- 選んだレベル以下の料理だけ（ハードフィルタ）。0 は style に外食を含むか deliAlt の料理だけ＋「作らない前提で…」表示
- 包丁なし指定は knife 不要のみ
- 3品未満ならレベルを1つ上げて再計算し「やる気の範囲では候補が少なかったので、少しだけ手間が増える料理も入れています」
- アキネーターモードの最初の質問「今日のやる気は？」（スキップ可）。進捗はやる気度込みで Q1/8
- フリー入力：作りたくない→0、温めるだけ→上限1、茹でるだけ→上限1＋茹でる、炒めるだけ／焼くだけ→上限2、めんどくさい→上限2、凝りたい→4、包丁なし→knife 不要。複数あれば低い方。拾えたらやる気度の質問は質問済み
- 結果にやる気バッジ（［炒めるだけ］［包丁なし］）と理由
