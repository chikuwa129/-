# 設計メモ(参考。試合エンジン)

下の仕様書(T1)の土台です。設計の案で、数値は、すべて**仮**です。仕様書と食い違うときは、**仕様書を優先**してください。このメモは、`docs/design_game_engine.md` として、保存してください(内容は変えない)。

---

## 1. 目的と範囲

- **共通の土台**:能力と状況から、打席の結果の確率を出す式を、新入部員モードと監督モードの、両方で使う。
- **新入部員モード**:同じ式を、チーム単位に足し合わせて、試合の得点と失点にする。納得感(相手の格、結果の説明、ルーレット)の土台になる。
- **監督モード**:打席ごとに、データを読んで、指示を出す。指示が確率を変え、シミュレーションで結果が出る。
- **参考にするもの**:原作の育成ゲームの、指示の仕組みの**考え方**。名称、数値、素材は、使わない(第1回の方針:すべて自作)。原作の指示の一覧は、あなたが確認して、足りない所を足す。

---

## 2. 全体像

```
打席の結果の確率 P(結果 | 投手, 打者, 状況, 指示)
   ├─ 打席単位(監督モード):確率から抽選して、1打席ずつ進める。指示を受け付ける
   └─ チーム単位(新入部員モード):同じ確率を、走者とアウトの状態遷移で足し合わせ、
        1試合の得点の分布を出す → 勝敗と点数を、1回の抽選で決める(いまと同じ「先に決める」形)
```

- 同じ式を、2つの解像度で使う。式を1つにすれば、新入部員モードで調整した数字が、監督モードの土台になる。
- 結果は、同じシードなら、同じになる(采配の「もしもの比較」の前提)。

| フライのアウト | |

- 走者の進塁は、簡易な規則にする(単打で、二塁走者は生還、など。走力で、進む塁が変わる)。

## 4. 能力から確率への、出口(案)

野手は、既存の5つの軸(ミート、パワー、走力、守備(肩を含む)、投手)で考える。

| 能力 | 効く先(案) | 現状 |
|---|---|---|
| 投手:球速 | 三振が増える。長打が減る | 要確認 |
| 投手:制球 | 四球が減る。甘い球(長打)が減る | 要確認 |
| 投手:変化球(総変化量、球種) | 三振が増える。球種で、ゴロが増える | 要確認 |
| 投手:スタミナ | 投球が増えるほど、上の効果が落ちる(継投の理由) | 先発の投球回には、効いている |
| 打者:ミート | 三振が減る。単打が増える | 要確認 |
| 打者:パワー | 長打、本塁打が増える | 要確認 |
| 打者:走力 | 内野安打、進塁、盗塁 | 盗塁の成績まで。得点、勝敗には効いていない(H1.6a の報告) |
| 守備側:守備 | ゴロ、フライのアウトが増える(安打が減る) | 要確認 |
| 守備側:肩 | 進塁を防ぐ。盗塁を阻止する | 要確認 |

- **表示する項目は、実際に効いているものだけ**にする。効いていない項目は、先に効かせてから、表示する。
- すべての能力に、出口が要る(出口のない能力は、采配の材料にならない)。

## 5. 確率の作り方(案)

1. 各結果に、**高校野球の水準の平均**(基準の確率)を置く。
2. 投手と打者の能力の差で、基準の確率を、増やしたり減らしたりする(差が大きいほど、効く。上限と下限を持つ)。
3. 守備側の質で、打球のアウトの割合を、調整する。
4. 状況(走者、アウト)と、指示で、さらに調整する(次の節)。
5. **較正**:新しい式の出力を、いまのゲームのバランスに合わせる。
   - 強さの差ごとの勝率
   - 得点の分布
   - 先発の総合値の帯ごとの防御率(第4回の表)
   - 既存のバランスを壊さずに、中身だけを置き換えるため。

## 6. 指示(采配)の候補と、効き方(案)

効きは、すべて**方向だけ**。大きさは、遊んで決める。

### 投手側

| 指示 | 効き(方向) | トレードオフ |
|---|---|---|
| 直球中心 | 三振が増える(球速が高いほど)。長打が増える(制球が低いほど) | 読まれると打たれる |
| 変化球中心 | 三振、ゴロが増える。四球が増える(制球が低いほど) | 球数が増える。制球が低いと崩れる |
| 外角中心 | 長打が減る。四球が増える | 甘いと、狙い打たれる |
| 内角中心 | 三振、詰まりが増える。死球、長打が増える | 制球が低いと、危険 |
| 敬遠、勝負回避 | その打者の結果を避ける。次の打者と、走者が増える | 満塁の危険 |
| 継投 | スタミナの低下を、リセットする。相性を変える | 後の投手が、足りなくなる |
| 牽制、クイック | 盗塁を、阻止しやすくする | 打者への球が、甘くなる |
| 守備位置(前進、通常) | 本塁への生還を防ぐ。長打のコースが、空く | 状況で、損得が変わる |

### 打者側

| 指示 | 効き(方向) | トレードオフ |
|---|---|---|
| 長打狙い | 長打、本塁打が増える。三振が増える | ミートが低いと、空振りが多い |
| 短打狙い | 三振が減る。単打が増える。長打が減る | 得点が伸びにくい |
| 送りバント | 走者が進む。アウトが1つ増える | 得点期待値は、状況で上下する |
| スクイズ | 三塁走者が生還する | 失敗すると、走者が、アウトになる |
| 盗塁 | 成功すると、1つ進む | 失敗すると、アウト。成功率は、走力、相手の肩、クイックで決まる |
| エンドラン | 進塁が増える。併殺が減る | 空振りで、走者がアウトになる |
| 代打、代走、守備固め | H1.6a の仕組みと、つなげる | 交代の枠が減る |

- **どの指示も、常に最善、とならないようにする**(状況で、最善が変わる)。データを読む面白さは、ここにある。
- 指示の効きは、**期待得点(または勝率)に、小さく、条件付き**で効かせる。
- 指示の効きが見えるように、選ぶ前に、確率の変化を見せる(例:「長打:+4%、三振:+6%」)。

## 7. 実データの参考(出典付き)

出典ごとに、前提と基準が違う。数字を直接つなげず、**方向性と、桁の目安**にとどめる(プロ野球モードのメモと同じ方針)。

- **盗塁の損益分岐点**:成功率が、おおむね70%以上でないと、得点の面で損になる、という趣旨の紹介がある。出典:講談社「統計学が見つけた野球の真理」の紹介ページ(https://www.kodansha.co.jp/titles/1000042283)。本の紹介文であり、本文は確認していない。
- **送りバント**:プロ野球(2014〜2018年)で、無死一塁の得点確率は 40.2%、一死二塁は 39.4%、という数字を引いた記事がある。バントが、得点確率を下げる傾向を示す。出典:Sportiva(集英社)の記事(https://sportiva.shueisha.co.jp/clm/baseball/npb/2024/04/27/post_125/?page=2)。記事が日経電子版の記事を引用している形で、元の記事は確認していない。**高校野球では、結論が変わる可能性がある**(金属バット、打者の層が違う)。
- **高校野球の水準(参考)**:夏の甲子園(2015〜2017年。各年48試合として、私が割った概算)の、年ごとの本塁打は、32、37、68本。盗塁は 98、82、87。犠打は 185、185、194。平均得点は、9.71、8.94、11 とある(1試合の両チームの合計と思われるが、定義は未確認)。出典:明治大学の卒業論文(https://www.kikn.fms.meiji.ac.jp/paper/2017/bachelor/paper/masatatsu.pdf)。学生の論文なので、参考程度に使う。
- **得点期待値の考え方**:走者とアウトの状況ごとに、1イニングで見込める得点を出す。状況ごとの、作戦の損得を比べる基礎になる。出典:FanGraphs ライブラリの RE24 の説明(https://library.fangraphs.com/misc/re24)。

## 8. チーム単位への集計(新入部員モード)

- 打順の9人と、先発、救援(最大3人)の切り替えで、**走者とアウトの状態(24通り)**を遷移させる。各打者の確率は、5の式で出す。
- 1イニングの得点の分布 → 9回(と延長)の得点の分布 → 勝率、の順に出す。これは、行列の計算で、軽い(24通りの状態)。全参加校のトーナメントでも、軽く済む見込み(要確認)。
- 勝敗と得点は、1回の抽選で決める(いまと同じ。「先に決める」)。そのあとで、回ごとの得点を割り振る(H1.9 の確認で、いまも、そうなっていることを確認)。
- 同じシードなら、同じ結果。旧挙動に戻すスイッチを付ける。
- 先発の失点の補正(いまの heroRunsAllowed)は、この式の中に入れる。相手の打撃が、失点に効く(「格上の打線に打たれた」が、実際の仕組みと合う)。

## 9. 検証の物差し(sim)

- **較正**:強さの差ごとの勝率が、いまと、±2ポイント以内。防御率の帯の表(第4回)を、再現する。得点の分布が、近い。
- **指示**:どの指示も、支配的にならない(常に最善の指示が、ない)。各指示に、有利な状況と、不利な状況が、ある。
- **盗塁**:損益分岐点が、成功率70%前後になるように、効きを調整する(7の出典の考え方。高校野球に合わせて、動かしてよい)。
- **既存の物差し**:上位10%の維持、下位半分から上位20%に入る割合、などを、悪化させない。
- **速度**:大会の1回分を回して、体感のテンポが変わらない(重くなったら、新入部員モードでは外す選択肢を残す)。

## 10. 進め方(案)

| 段階 | 内容 | Claude Code の使用量 |
|---|---|---|
| 0 | 読み取り:いまの試合の計算、投手と守備の効き方、監督モードとの共有範囲 | 軽い |
| 1 | この設計メモ(あなたが、判断して、直す) | なし |
| 2 | **一打席の試作**:単体の小さな画面。投手と打者のデータを見て、指示を選び、確率が出る。面白さを、小さく試す | 小〜中 |
| 3 | 新入部員モードの集計版。トーナメント表、相手の格、ルーレットを、この上に乗せる。旧挙動のスイッチ付き | 中〜重 |
| 4 | 監督モード | 重 |

- 作り込みすぎない。段階2で、采配の面白さを確かめてから、先に進む(第3回の教訓:足したものの多くは、面白さにつながらなかった)。

## 11. 未決事項(あなたの判断)

1. 原作の指示の一覧を見て、足りない指示を足す(守備のシフト、バットを短く持つ、など)。
2. 四球を、何で決めるか(選球眼の能力を足す、ミートで代用する、制球だけで決める)。
3. 守備と肩の効き方(位置ごとに分けるか、チーム全体の1つの値にするか)。
4. 一打席の試作の範囲(投手側の指示だけ、打者側の指示だけ、両方)。
5. 新入部員モードで、集計版を入れる前に、トーナメント表と相手の格(総合値1本)だけ先に入れるか。
