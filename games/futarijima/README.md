# ふたりじま

ゲームボーイカラーの『サバイバルキッズ2 脱出!!双子島!』（コナミ、2000年）を参考にした、**オリジナル**の無人島サバイバルゲームです。
キャラクター・マップ・絵・音・文章はすべて新しく作りました。参考にしたのは「双子島で兄弟が離れ離れ」「空腹・のど・疲れのメーター」「アイテムを合わせて道具を作る」「エンディングが複数ある」というジャンルの骨組みだけです。

`index.html` をブラウザで開くと遊べます（ファイル1つだけで、画像ファイルは使っていません。絵も音もコードで作っています）。

| 移動 | 矢印 / WASD | 十字キー |

| ひとやすみ（目標・ひらめきメモ・エンディング） | Enter / Esc | START |

- 西の島で目をさました兄**カイ**になって、東の島にいる弟**リク**と合流し、島を脱出します。
- 時間がたつと **食（おなか）・水（のど）** が減り、**疲（つかれ）** がたまります。どれかが尽きると **体（体力）** が減っていきます。

- 寝床で眠ると次の朝になり、セーブされます。
- エンディングは4つあります。

## 桜井スキル（[kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)）をどこで使ったか

番号は「桜井政博のゲーム作るには」の動画の通し番号です（スキルの `references/` にある番号）。

### 企画の核
- **面白さの核を一言で**：「遠くの危ない所ほど良い材料がある。それで作った道具が島を楽にする」。
- **クラフトにリスクとリターンを絡める**（#026 クラフト系）：材料を取ると疲れがたまる。夜や草むらにはヘビが出る。なまの魚や肉はすぐ食べられるが、おなかをこわすことがある。焼けば安全で、回復量も多い。
- **作業ゲームは「稼ぐ→作業を楽にする道具」が核**（#201）：素手だと枝しか取れない木が、オノを作ると丸太になる。水筒を作ると、わき水まで戻らずに済む。
- **リスクを目に見える形で置く**（#006 / #191「隠れる」）：ヘビは草むら（背の高い草）からしか出てこない。草むらを刈ると、かれ草が取れて安全にもなる。スタートの浜のまわりと、最初の手ほどきの間は出ない。昼は2匹まで、夜は5匹まで。
- **答えを文字で出しすぎない**（#085 自然なチュートリアル）：カバンで「あわせる」を選ぶと、合成できる相手だけが明るくなり、カーソルもそこだけを渡る。何と何が合わさるかは文字で教えない。
- **詰ませない**（#211 クリアできないよりマシ）：つるの木はオノでも切りたおせない。つるが取れなくなって進めなくなる道を消した。
- **材料のありかを見た目で伝える**（#030 判定のあるものを強調する）：つるは、黄緑のつるが巻きついた木から必ず取れる。目標の1行に「ロープ＝つる＋つる（いま 1/2）」と、あと何本かを出す。
- **ギュッとしてパッと解消**（#009）：のどやおなかがピンチになると、バーが点滅して音で知らせる。食べて飲むと、数字が浮かんでバーが一気に戻る。

### 導入・テンポ
- **最初の3分で面白さを伝える／いきなり見せ場から**（#017 / #233）：オープニングは画面が上下に分かれ、別々の島で目をさます兄弟を見せる。約5秒で、A ですぐ飛ばせる。そのまま本編に入る。
- **チュートリアルは本編の形で**（#085）：画面下に「いまやること」を1行だけ出す。できたら次の行に進む（いしを拾う → あわせる → ヤシの実 → 飲む）。
- **押して何も起きないボタンを作らない**（#104）：何もない所で A を押しても空ぶりの動作と音が出る。取れないものには理由を一言出す。
- **遅さは罪**（#073）：落ちている物は歩けば拾う。A ひとつで「その場で一番自然な行動」を選ぶので、道具を持ちかえる操作がない。カバンは前回選んだ項目（つかう/あわせる）を覚えている。
- **リトライは迅速に**（#116）：倒れてもゲームオーバーにしない。次の朝に寝床で目をさまし、持ち物もそのまま残る。

### 手応え
- **ヒットストップ**（#003 / #047）：木を叩くと4F、木が倒れると10F、ヘビを叩くと6F、ダメージを受けると9F止まる。止まっている間の入力は先行入力として残る。
- **構えは瞬時に極端に**（#049）：A を押した1フレーム目で体を沈め、道具を後ろへ振りかぶる。振る時は風切りの線を出す（#140）。
- **画面振動は大中小で揺れ方を変える**（#103）：小は縦だけ、中は縦が主、大（木が倒れる、橋がなおる）は横が主。
- **フラッシュは明暗を交互に**（#221）。
- **効果音は影響度順の音量**（#032）。叩く音はアタックを強めにした（#165）。

### ご褒美・目標
- **目の前に吊るしたご褒美**（#023）：壊れた橋の向こう岸で、弟が手を振っているのが見える。最初の大きな目標が目で分かる。
- **良いおつかい**（#064）：弟を仲間にするには食べ物を渡す。距離が短く、報酬は「仲間になる」。仲間になった弟はときどき材料を見つけてくれるので、小さな喜びが続く。
- **ほめる**（#095）：初めて作れた道具は「ひらめいた!」とファンファーレで知らせる。ひらめきメモ（16種）とエンディング（4種）を集める楽しみがある。
- **攻略を一本道にしない**（#217）：島を出る方法は「いかだ」と「のろし」の2つ。いかだは帆があるかないかで結末が変わる。弟を置いて出ることもできる。

### UI・調整
- **HUD は状態で見せ方を変える**（#252）：メーター4本は漢字1文字のアイコン付き。危ない時だけ点滅する。
- **キャラはシルエットで立てる**（#241）：兄は赤、弟は青＋黄色のバンダナにした。すべてのスプライトに黒い縁を付けた。
- **判定のある物を強調**（#030）：通れない木・岩・茂みは濃い色と影で描いた。地面は明るい色で、模様を控えめにした。
- **調整したい数値は外に出して【日本語名】で**（#046 / #068）：`index.html` の先頭にある `P` に、`【おなかが空になる秒数】` などの名前でまとめた。
- **デバッグモード**（#193）：F1 状態表示 / F2 時間4倍 / F3 材料をもらう / F4 無敵。
