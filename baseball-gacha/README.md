# 野球ガチャ育成ゲーム(試作版)

高校野球の監督になって、新入生の「引き」と数年後の「答え合わせ」を楽しむ放置寄りの育成ゲーム。
ビルド不要の静的ファイルのみで動きます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面(CSS・画面用スクリプト込み) |
| `logic.js` | ゲームロジック(DOM 非依存)。`Core`(選手生成・成長・記録の共通部分)と `HighSchool`(高校版の進行)に分かれている |
| `config.js` | 確率・補正値などの設定(すべて仮の値) |
| `sim.js` | Node.js で画面なしに何十年分も自動実行する検証用スクリプト |
| `play.html` | config.js と logic.js を埋め込んだ単一ファイル版(プレビュー用)。`build-play.js` で生成 |
| `build-play.js` | `node build-play.js` で play.html を作り直す |
| `benchmark.js` | 世代の基準(学年×月ごとの総合値の分布)。`node tools/build-benchmark.js` で生成 |
| `tools/build-benchmark.js` | 世代の基準を作り直す(初期能力・成長・成長限界・項目上限を変えたら実行) |
| `tests/reset.test.js` | リセットの自動確認(`node tests/reset.test.js`) |
| `tests/lineup.test.js` | スタメン編成(本職優先)の自動確認(`node tests/lineup.test.js`) |

## 遊び方

`index.html` をブラウザで開くだけ(ダブルクリックで可。config.js・logic.js と同じフォルダに置くこと)。
ファイル1つで開きたい場合やプレビュー画面では `play.html` を使います。config.js・logic.js・index.html を直したら `node build-play.js` で作り直してください。
セーブは自動で localStorage に保存されます。

- 1年は4月始まりの12か月。ホーム上部の帯で今の月が分かる
- 「次のイベントまで」:入学・合宿・大会・年度末(と重要な通知)のある月まで進む。途中の月は1行ずつまとめて表示
- 「次の月へ」:1か月だけ進む /「次の4月まで」:1年分をまとめて進める
- 4月:新入生(人数はチームの強さで3〜12人)がやってくる。能力を見て「入部させる」。育成方針は常におまかせ(能力から自動で決まる)
  - 方針を自分で選ぶ画面(4月のプルダウン・12月の見直し)は、policyControlEnabled を true にすると戻る(?dev=1 の調整タブ)
- 総合値 = 本職側の能力の平均 × 5。天才・転生は能力が100を超えることがある(金色で表示)
- 総合値の横のラベル(有望・逸材・怪物級・規格外)と「同世代 上位○%」は、世代の基準と比べて決まる
- 設定タブ:「同じシードでやり直す」「新しいシードで始める」「セーブを完全に消す」。URLに `?reset=1` を付けて開いても全部消える
- スタメンは本職を先に決める。本職外の起用(赤字)は、その守備区分の本職が足りないときだけ
- ホームの並び:スタメン → 注目選手 → 月のまとめ(未読の間は「●新着」)→ 最近の出来事。homeSummaryPosition(?dev=1 の調整タブ)で、まとめを上に戻せる
- 見直し画面と入学画面では、能力を項目ごとの大きな数字のボックスで出す
- 試合はラインスコア・勝敗投手・活躍選手などを「詳しく」で見られる(勝率予想・チーム戦力・他校との比較は遊ぶ画面には出さない)
- 成長タブ:毎月の全在校生の能力の変化(前月・次月、絞り込み、小数表示)。年度末に「今年のまとめ」
- 調整タブ(URL に ?dev=1 を付けたときだけ表示):設定値の変更(次の新しいゲームから有効)、進行中のゲームの集計、「この設定で試す」(試し計算)、世代の基準の再計算
- 表示はテンポ優先:最初は1行の要約だけ。「▸ … 詳しく」を押すと詳細が開く(開閉はパネルごとに記憶)。設定タブの「表示の詳しさ」で 最小/標準/詳細 を切り替え
- 開始時の2・3年生は、就任前の数年(前史)を通常のルールで内部シミュレーションして作る。履歴には「(開始前)」が付く
- 学校の評判:毎年3月に大会成績・プロ入り・指導力から更新。評判が高いほど新入生の上位層と天才・転生が増える(4月に「今年の新入生の傾向」)
- セーブデータは形式のバージョン番号を持つ。古い形式のセーブは自動で初期化される

## 検証

```bash
node sim.js            # 50年 / シード12345 / 方針auto
node sim.js 200 42 random
```

引数は `[年数] [シード] [方針(auto|balance|random)]`。シードから10本ぶん実行し、config.js の目安(targets)と比べて ✓ / △ / ✕ を出します。同じシードなら同じ結果になります。

設定を変えたら:`node tools/build-benchmark.js` → `node build-play.js` の順に実行してください。
